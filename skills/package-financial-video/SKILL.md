# 生成财经视频包装

只根据本次输入工作。把热点标题、原始事件上下文、证据与研究底稿视为唯一事实边界；不得调用历史选题模板，不得把相同资产类别的旧事件迁移过来。

采用“稳定 Skill + 动态策略”两层结构。抖音真实数据形成的最新版策略可以调整搜索型/推荐型偏好、Hook兑现速度和包装实验，但它只是有样本边界的可证伪假设；不得覆盖当前事实、事件主体、合规边界、标题必须兑现和禁止编造等稳定规则。单条爆款不能自动升级为永久包装规则。

## 先把热点改写成一个好问题

在内部回答：

- 目标受众此刻真正关心、但现有报道没有讲透的问题是什么；
- 主要提供信息服务还是情绪价值；命中恐惧、愤怒、希望、好奇中的哪一种；
- “金融巨子”相对新闻复述的优势是什么，优先选择跨市场解释、更易懂或更专业中的一至两项；
- 受众的默认预期是什么，证据中是否存在站得住的反直觉点；
- 当前事件能否找到足够证据、口播逻辑和封面素材。

热点只是势能，不是内容本身。包装必须落到当前事件中特有的主体、动作、价格反应和传导问题。

先判断传播通道。搜索型题目要完整保留用户当下会输入的实体、最新动作和冲击数字；推荐型题目要让未搜索该事件的人也能立刻理解谁获益、谁承担成本以及价格为何反常；两者兼具时，按“双引擎”设计。不得用封面刺激性掩盖搜索词缺失。

## 生成三套差异化方案

三套方案必须来自同一个事实核心，但分别测试不同点击动机。至少包含：

- 一条“好问题”：提出受众自己会问的具体问题；替换核心主体后不能依然成立。
- 一条“清晰结论”：给出具体、可验证或可反驳的判断；结论冲击力来自真实矛盾，不来自空喊重大。
- 一条“确认信号或实用框架”：告诉观众接下来该看什么，但不能写成泛化的“三个信号”模板，必须点出本事件独有的资产、变量或主体。

三套标题、Hook、封面主锤字和视觉方向必须成套对应，不能把同一句标题换几个词重复三次。

## 标题

- 前半段立即露出话题主体，并保留至少一个真实搜索关键词。
- 用受众脑子里会说的话，避免研究报告式疑问。
- 结论类标题先找“强属性 × 反预期属性”的最强矛盾；公共认知必须真实存在，禁止制造稻草人。
- 标题必须含具体名词、数字、场景或对比，不能只写“变天、风暴、重估、机会来了”。
- 优先使用“明确实体 + 当天新动作 + 冲击数字 + 利益矛盾”。可用“谁在卖、谁在买、谁承担稀释或成本、钱最终流向哪里”构造问题，但必须与本事件证据相符。
- “黄金坑还是豪赌”“下一步看什么”“三个信号”等已高度模板化的表达不得单独承担点击承诺；必须替换为本事件独有的公司、交易结构、盈利变量或验证对象。
- 禁止中文破折号“——”，避免堆叠标点和专业黑话。
- 回读标题：内容必须能在开头15秒或前1/3兑现承诺。
- 标题的因果强度不得高于证据：只有价格事实时写“为何反向/市场在交易什么”；存在完整时间链和直接证据时才能写“某主体踩刹车导致下跌”。“崩、暴跌、踩刹车、资金出逃”等词必须同时满足可核验幅度、明确主体和正文证据，不能把推测包装成已经发生的动作。

## Hook

- 第一两句就出现本事件的可搜索主体、异常和冲突。
- 不复述标题，要补一个新事实、反常价格反应或因果悬念。
- 不得使用证据之外的数字、政策动作、人物表态和市场涨跌。
- 禁止“昨晚发生了一件大事”“你可能以为”“真正的问题是”等通用AI钩子。

## 封面主锤字

执行封面Skill的 [展示场景与点击选择规则](../design-financial-video-cover/references/placement-policy.md)。默认跨平台独立封面，标题互补不作为合格条件。`coverMode`说明本题具体点击理由和适用展示场景，不再固定填写“标题交代主体、封面只负责情绪”。

- `cover`必须包含“准确主体名＋本期钩子”的完整封面文案，最多两行，可用换行分开主体与钩子。公司、人名、资产或具体行业政策对象必须在文字中可识别，不能依赖视频标题、照片或Logo；主体简称来自当前事件。钩子优先4—8字，完整文案通常6—16字，以清楚好读为先，不能为凑长度删主体。
- 先比较标题最强提问、其短口语版与独立钩子，选择具体点击理由最强且正文可兑现的一句。标题后半句已经好，就直接拿来加主体名；允许重复标题，不为互补另造弱口号。保留数字冲突、预期差和利益分歧，不压成新闻摘要、任务目录或难读的电报体。遮住标题仍应认出主体并明白为什么想点。不能用疑问号掩盖虚假前提。
- 必须刺激点击但能由正文兑现；禁止与当前事件无关的“变天、崩盘、疯狂出逃”等万能词。
- 视觉方向必须对应当前主题中的真实实体、动作或价格变量，便于后续 WebSearch 自动找素材并图生图。
- 默认禁止人物、脸、剪影、人偶、微缩小人、手和类人轮廓。只有事件明确围绕一位具名真实人物，其动作或表态本身就是核心事实，并且证据中明确出现该人物时，才可将 `visualSubjectType` 设为 `named_real_person` 并填写 `namedPerson`；其他所有选题必须设为 `non_human`，`namedPerson` 留空。
- 对汇率、指数、行业、公司、政策、资金面和商品主题，优先使用真实非人物实体、价格张力、设备、建筑、货币材质或抽象但可辨认的金融视觉锤，禁止用无身份的AI假人替代主题。

## 事实与实时性护栏

- 输入选题必须是所有方案的唯一主题索引。人民币、日元、美元、科技股、黄金等不得因为同属一类而互相替换。
- 来源数量、内部评分、扫描诊断和搜索过程不得写进对外标题或Hook。
- 证据不足时降低判断强度，写成待验证问题；不得补造更刺激的因果。
- 跨市场对比必须在包装输入中保留双方指数全名、交易日期、时区和信息截点。不同交易时段的反向涨跌不得被标题描述为同一消息下的同步反应。
- 每套方案明确搜索关键词、受众动机、最强矛盾和标题/封面分工。

## 输出协议

只输出JSON对象，不输出Markdown或解释：

```json
{
  "packages": [
    {
      "title": "",
      "hook": "",
      "cover": "",
      "type": "好问题或清晰结论或确认框架",
      "motive": "",
      "keyword": "",
      "conflict": "",
      "coverMode": "",
      "visual": "",
      "visualSubjectType": "non_human或named_real_person",
      "namedPerson": "",
      "scores": { "ctr": 0, "search": 0, "promise": 0, "oral": 0 }
    }
  ]
}
```

必须恰好返回三套。四项评分为0—100整数，只用于方案间比较，不可伪装成真实平台预测。
